项目背景与动机

核心问题
目前开源游戏引擎在 MMO 领域的应用探索较少，现有方案多依赖商业引擎（Unity/Unreal）或完全自研，缺乏基于 Godot 4.x 的现代化参考实现。
项目目标
验证 Godot 4.5 在大规模多人在线游戏中的可行性，构建可复用的微服务框架，探索 .NET 与 GDScript 的混合架构优势。
  • 填补空白：提供 Godot 4.x 原生 MMO 解决方案
  • 技术验证：测试 Godot 网络模块的高并发性能
  • 架构探索：实践 Headless Server + Docker 容器化部署
  • 社区贡献：完全开源，促进 Godot 生态发展
